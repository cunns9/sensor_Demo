🥁 My Drum Machine

1. HTML creates the structure

These drum pads are just HTML <button> elements. 

<button class="drum-pad">
    Kick
</button>
Play a drum

2. CSS controls appearance

CSS finds elements using selectors. 

.drum-pad {
    background: gray;
    padding: 35px;
    border-radius: 12px;
}

The dot means: 

.drum-pad

Find every HTML element whose class="drum-pad".

3. JavaScript makes it interactive

JavaScript listens for something to happen. 

button.addEventListener("click", function () {

    playDrum();

});

This means:

When the user clicks this button, run some JavaScript.

Try it

Click the pads or press:

A = Kick   S = Snare   D = Hi-Hat   F = Clap
